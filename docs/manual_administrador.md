# Manual de administración

Ingresá con una cuenta administradora para gestionar residentes, pagos, caja, personal, turnos, tareas, normas y la configuración institucional.

- En **Configuración** se actualizan los datos institucionales, SMTP, obras sociales, medios de pago, porcentajes y categorías de caja.
- En **Personal** se crean empleadas y se generan o regeneran invitaciones de acceso.
- En **Tareas** y **Normas y políticas** se publica la información operativa para las empleadas.
- En **Copias de seguridad** se descarga un ZIP de la base y los archivos cargados.

No compartas usuarios, contraseñas ni archivos de backup fuera del equipo autorizado.
